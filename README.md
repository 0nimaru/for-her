# For her 💌

Static site, no build step. Files: `index.html`, `styles.css`, `app.js`.

## Deploy to Vercel
    npx vercel --prod
(or push this folder to GitHub and import it at vercel.com/new, Framework preset: "Other")

## Testing tips
- Add `?reset` to the URL to wipe saved progress (the page remembers which card she was on).
- Accepted names: ada, adela, adelka, adys, adysa (any case, accents, emoji or symbols ignored).
